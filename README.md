## Correr proyecto
Antes de correr el proyecto debemos asegurarnos que las dependencias esten instaladas (node_modules). Si aún no se encuentran instaladas, se deberá correr el comando *npm install* para instalarlas.

### Correr proyecto desde el navegador
Para correr el proyecto y ver los cambios desde el navegado, se deberá correr el comando *npm start*
